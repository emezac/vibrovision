# Demonstration video

[Download or play the combined demonstration](vibrovision_hackathon.mp4) (3:17, 1920×1080, H.264/AAC, English narration in the application segment).

The first 49 seconds are the existing illustrated explanation. The companion shows the original fan recordings, recorded AWS interface, measured spectra, a structural-model illustration, a real synthetic-test agent trace, and the deployed architecture. [English captions](vibrovision_hackathon_en.srt) start with the narrated companion; the illustrated introduction already contains English explanations.

The team can add a brief personal introduction before its final Devpost video submission. No personal footage was supplied for this edit.

`verification.json` records the checked movie hashes and source jobs. The standalone companion referenced by that record remains a separate editing deliverable; this repository includes the combined video. Both movie files were fully decoded without errors during verification.

The source fan clips are in `data/real/`. Numeric result callouts come from `results/aws_demo_comparison.json`; the spectral curves come from the earlier local analysis of the same recordings. The structural diagram is illustrative, and the agent trace is explicitly identified as synthetic. No field sensitivity or COOL acceleration is claimed.

The cards, diagrams, transitions and score were generated for this project. The English narration uses the synthetic en-US-AriaNeural voice through edge-tts 7.3.1 and is not presented as a team member's voice. No InventorOS media or third-party background music is reused.
